## Overview
A simple travel blog with a landing page and a blog post page, based on my wireframes.

## W3C validation
HTML and CSS were checked with the W3C validators (screenshots attached).

## Responsive
Mobile: hamburger menu, one-column cards. Desktop (900px+): horizontal menu, 3-column cards, post with sidebar. Uses CSS Grid, Flexbox and a media query.

## Styling
Simple palette defined with CSS variables, clean Arial typography, consistent spacing.

## Four extras
1. CSS-only hamburger menu (no JavaScript).
2. CSS variables for the color theme.
3. HTML5 form validation on the newsletter email field.
4. Hover transitions on buttons and menu links.
